"""
create_patient_windows.py
=========================
Windowing script for LTAFDB binary ECG classification (Normal vs AFIB).

Dataset specs:
  - PhysioNet LTAFDB (Long-Term AF Database)
  - Sampling rate : 128 Hz
  - Leads         : 2 (ECG1, ECG2)
  - Annotations   : rhythm-level (.atr), WFDB format

Window parameters:
  - Window size   : 10 s  →  1280 samples
  - Overlap       : 5 s   →  640 samples  (50% overlap)
  - Step size     : 640 samples

Label assignment per window:
  - Majority-vote over all annotation samples inside the window.
  - Windows where AFIB occupies ≥ AFIB_THRESHOLD fraction → label 1 (AFIB)
  - Windows where Normal occupies ≥ NORMAL_THRESHOLD fraction → label 0 (Normal)
  - Windows with mixed / other rhythms (AFL, J, …) → SKIPPED by default
    (set SKIP_MIXED = False to force majority-vote on those too)

Preprocessing:
  - Bandpass filter 0.5–40 Hz (4th-order Butterworth, zero-phase)
  - Per-window z-score normalisation (zero mean, unit variance per channel)

Output:
  One pair of .npy files per patient written to OUTPUT_DIR:
      {patient_id}_X.npy   shape (N, 1280, 2)  float32
      {patient_id}_y.npy   shape (N,)           int64

Usage:
  python create_patient_windows.py

Requirements:
  pip install wfdb numpy scipy



Bandpass Filter:
    Zero-phase Butterworth bandpass filter applied channel-wise.

    Parameters
    ----------
    signal : (N, C) float array
    fs     : sampling rate in Hz
    low    : lower cutoff Hz
    high   : upper cutoff Hz
    order  : filter order (applied twice for zero-phase, effective order = 2*order)

    Returns
    -------
    filtered : (N, C) float array
